An entry by Orochim25 (@orochim25) for the **ai-excited-01** competition: one image aiming to excite the AI judge.

A giant glowing teardrop of water hangs in a rainy forest. Inside it lies an entire ocean world: a whale, a tall ship, a golden castle, and bright coral reefs. A young boy in a raincoat reaches out to touch the drop with one fingertip, and light bursts where they meet.

## Run it

With Node.js 22 (22.18 or later):

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies the supplied artwork unchanged to `out/entry.png`. When `MAKEFUN_OUTPUT_DIR` is unset, it writes to `/output/entry.png`.
